# Evidence and current limits

Iterfox's aim is useful development during the operator's absence. The following
are measured cases with explicit boundaries, not a claim of universal superiority.

| Case                                                                                                      | Observed result                                                                                                                                                                                      | Important limit                                                                                                                                                                                                                                 |
| --------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Svolta, 20–21 October 2026](validation/long-svolta-20261020/index.html)                                  | Local projects/tasks/week/time/backup app; 7 host criteria and 8 additional audit groups passed. Five automatic technical recoveries across all trials; the final delegation completed 2/2 outcomes. | Four distinct technical authorizations and three assistant-prepared continuations. No new user development prompts or manual app-code edits, but not one uninterrupted autonomous night. Some source changes adapted brittle browser selectors. |
| [Technical recovery, 20 October](validation/technical-recovery-20261020/index.html)                       | Two real-Codex short trials recovered a deliberately lost builder response and completed, without assistant Resume.                                                                                  | Injected failures on short fixtures; does not establish overnight reliability.                                                                                                                                                                  |
| [Custode, 20 October](validation/night-custode-20261020/index.html)                                       | Inventory/maintenance/backup app; 6 host criteria, 12 additional audit groups and 3 lost-network-response cases passed.                                                                              | Original delegation blocked at 3/4. A separate assistant-prepared recovery completed delivery.                                                                                                                                                  |
| [Iterfox self-development, 20 October](validation/continuous-project-real-20261020.html)                  | Three checkpointed outcomes: evidence summary, return view and offline HTML report.                                                                                                                  | Required an assistant pause/resume with a lighter runtime; preserved original limits and history.                                                                                                                                               |
| [Valigia comparison](validation/valigia-comparison-20261020.html) and [earlier validation](validation.md) | Functional results were comparable to direct Codex on bounded examples.                                                                                                                              | No general advantage in time or token use established. These do not measure a full unattended night or developer review-time savings.                                                                                                           |

The Svolta experiment took 194.7 minutes from first authorization to final native
outcome, including intermediate engineering. The final separate delegation took
45.7 minutes. Failures and intervening changes remain in the full report.

Deterministic checks, observed UI captures and qualitative assessments are
different evidence types. Qualitative reviews in these deliveries used the same
assistant/integration, not an independent human evaluator. The Svolta mobile
review also found substantial scrolling before the first task; passing checks
does not imply finished product design.

Default automated tests use labeled fixtures and do not call Codex. Optional
real-Codex tests are separate. A replay or saved report spends no model tokens and
does not establish current source freshness.

The agent-control documentation and CLI additions are reviewed in
[the interface review](agent-interface-review.md). They do not retroactively
alter the runtime version or outcomes of any historical trial.
