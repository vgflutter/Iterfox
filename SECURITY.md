# Security

Iterfox 0.1 is a local development tool for repositories and check commands you
trust. It is not a security boundary against malicious code or a compromised model.
Read [the operational boundaries](docs/safety.md) before unattended use.

Please report security issues privately through the repository's GitHub
[private vulnerability reporting](https://github.com/vgflutter/Iterfox/security/advisories/new)
if enabled. Otherwise contact the repository owner through their GitHub profile
to arrange a private report. Do not include credentials, private code or full
unredacted ledgers in public issues. No hosted incident-response service is provided.
